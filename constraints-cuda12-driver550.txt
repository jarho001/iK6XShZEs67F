# Constraints for the CUDA 12 image on NVIDIA drivers near 550 (the lab machines run 550.163.01,
# which supports CUDA 12.4 natively). Use with requirements-cuda12.txt:
#   pip install -r requirements-cuda12.txt -c constraints-cuda12-driver550.txt
# Each CUDA library is pinned to the oldest release that jax-cuda12-plugin 0.12.0.1 allows, and to a
# CUDA 12.4 release wherever the plugin's floor is at or below 12.4. Two floors are above 12.4 and
# stay where the plugin needs them: nvidia-cuda-nvcc-cu12 >= 12.6.85 and nvidia-cudnn-cu12 >=
# 9.10.2.21 (pip cannot satisfy the plugin with 12.4 versions of them). The lab's preflight checks
# that JAX runs with these pins; see lab/README.md.
